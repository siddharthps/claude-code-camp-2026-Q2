# Claude Code Camp

Exploring autonomous agent architectures through extended gameplay in a CircleMUD environment. The challenge: build agents capable of sustained, adaptive play—navigating complex worlds, learning from failure, and coordinating specialized skills to achieve long-term goals.

This project investigates how agent design, infrastructure, and learning loops impact performance on open-ended tasks beyond simple automation.

This is the official repo for the Claude Code Camp operated by [ExamPro](https://www.exampro.co)
